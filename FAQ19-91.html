エイリアス設定のうち「エイリアス一対実アドレス多」の設定が仕様上不可とはどういうことか new!

エイリアス設定のうち「エイリアス一対実アドレス多」の設定が仕様上不可とはどういうことか、というご質問をいただいたことがあります。
ご質問の内容は、次のようなものでした。
メールサーバでアカウント taro@example.jp と、そのエイリアス taro.yamada@example.jp を運用していたところ、上位のシステムでアドレスが書き換えられるようになり、taro.yamada@sub.example.jp 宛てのメールも届くようになった。これも同じ taro のメールボックスで受け取りたいので、sub.example.jp のドメインを追加してエイリアスを登録しようとしたところ、「重複しています。」と表示された、というものです。
（ドメイン名・アカウント名は、説明用の例に置き換えています）

結論
E-Postシリーズのエイリアスは、エイリアスと実アドレスを一対一の関係で設定します。1つのエイリアスに複数の実アドレスを割り当てる「エイリアス一対実アドレス多」の設定は、仕様上できません。
一方、複数のエイリアスに同じ実アドレスを割り当てる「エイリアス多対実アドレス一」の設定はできます。ご質問のケースは、こちらの形で設定できます。


「エイリアス一対実アドレス多」を登録しようとするとどうなるか
同じエイリアスに2つ目の実アドレスを登録しようとしたときの動きは、使う画面によって異なります。

（1）Account Manager で登録しようとした場合
すでに登録されているエイリアス taro.yamada@sub.example.jp に、2つ目の実アドレス hanako@example.jp を登録しようとすると、「重複しています。」と表示され、登録されません。

（2）Mail Control の「エイリアス設定」タブで登録しようとした場合
Mail Control の「エイリアス設定」タブでは、同じエイリアスに2つ目の実アドレスを追加しても、メッセージは表示されずに登録できてしまいます。登録後は、Mail Control の一覧にも、Account Manager の一覧にも、同じエイリアスが2行並んで表示されます。

しかし、この状態で taro.yamada@sub.example.jp 宛てにメールを送ると、メールは1つ目の実アドレス taro@example.jp にだけ届き、2つ目の実アドレス hanako@example.jp には届きません。SMTP受信詳細ログ（receivelog）を見ると、エイリアスが1つ目の実アドレスにだけ置き換えられていることがわかります。
RCPT TO:<taro.yamada@sub.example.jp>
Check RCPT TO address = taro.yamada@sub.example.jp
    -> aliases = taro@example.jp
・・・
250 2.0.0 <taro.yamada@sub.example.jp>... Recipient ok.
設定画面では2行とも登録されているように見えるため、2つ目の実アドレスにメールが届いていないことに気づきにくい点にご注意ください。同じエイリアスを2行以上登録しないようにしてください。

「重複しています。」と表示される条件
Account Manager は、まったく同じエイリアスのアドレス（@以降のドメイン名まで同じもの）が、すでにどこかに登録されているときに「重複しています。」と表示します。
登録しようとしたエイリアス結果
すでに登録されているエイリアスと同じアドレス（実アドレスが同じでも、違っていても）「重複しています。」と表示され、登録されない
すでに登録されているエイリアスと同じアドレスを、別のドメインの Aliases に登録しようとした「重複しています。」と表示され、登録されない
@より前は同じで、ドメイン名が違うアドレス
（taro.yamada@example.jp がある状態で taro.yamada@sub.example.jp を登録）		別のエイリアスとして登録できる

ご質問のケースの設定方法
ご質問のケースでやりたいことは、3つのアドレス宛てのメールを1つのメールボックスで受け取ることで、「エイリアス多対実アドレス一」の形にあたります。そのため、追加したドメインにエイリアスを1つ登録するだけで実現できます。

1. ドメインの追加
Mail Control の「ドメイン管理」タブで sub.example.jp を追加し、［適用］をクリックします。続いて「サービス制御」タブで EPSTRS、EPSTDS のサービスを停止→開始で再起動します。
2. エイリアスの登録
Account Manager で sub.example.jp の［Aliases］を選択し、次のエイリアスを登録します。
エイリアス：taro.yamada@sub.example.jp
実アドレス：taro@example.jp

Account Manager から登録したエイリアスは、サービスを再起動しなくてもすぐに有効になります。

なお、アカウントもエイリアスも、ドメインごとに別のものとして扱われます。sub.example.jp のドメインを追加しただけでは、taro.yamada@sub.example.jp 宛てのメールは User unknown として受領を拒否されます。example.jp 側にある同じ名前のエイリアス（taro.yamada@example.jp）が、新しいドメインにも効くわけではありませんので、追加したドメイン側にもエイリアスの登録が必要です。

エイリアスを登録するときは入力の向きに注意
エイリアスは「エイリアス → 実アドレス」の向きで登録します。エイリアス欄と実アドレス欄を逆に入力すると、意図しない「エイリアス一対実アドレス多」の状態になったり、既存のアカウント宛てのメールが受信できなくなったりすることがあります。

登録したあとは、一覧で向きを確認してください。Mail Control の「エイリアス設定」タブでは「"エイリアス" -> "実アドレス"」の形で、Account Manager では［Aliases］列と［Address］列に分かれて表示されます。

1つのアドレス宛てのメールを複数の人に届けたい場合
1つのアドレス宛てのメールを複数のメールボックスに届けたい場合は、エイリアスではなく、メーリングリストや自動転送を使います。（下記の関連FAQ「エイリアス1つに実アドレス複数割り当ては不可、エイリアス複数に実アドレス1つの割り当ては可」参照）

（確認環境）E-Post Mail Server Standard (x64)（EPSTRS 4.AN、EPSTDS 4.84）、メールボックス方式は「共通ボックス（区別しない）」
