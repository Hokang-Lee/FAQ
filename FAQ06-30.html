EPSTDKIM 実装済み環境から EPSTDMARC に切り替える方法について new!

EPSTDKIM ツールを利用して既に実装済みになっている環境から、新しく ESPSTDMARC ツールを利用して切り替える方法と手順についての質疑応答事例です。

1. レジストリの設定で、「DomainAUTHDKIM」のパスを epstdkim.exe のパスから epstdmarc.exe のパスに変更するだけで切り替わるか。
はい。レジストリの設定のうち、「DomainAUTHDKIM」のフルパス表記を epstdkim.exe のパスから epstdmarc.exe のパスに変更するだけで切り替わります。念のために、変更後はEPSTRSサービスの再起動を行うことをお勧めします。

2. EPSTDMARC の readme には ARC の設定手順が書かれているが、ARC を使用しない場合にはどのような対応をとればよいか。
EPSTDMARC に含まれる ARC を使用しない場合で ARC を未設定にしておく際は、"epstarc.exe" のファイル名を変更し、例えば "~epstarc.exe" のようにリネームし、EPSTDKIM ツール本体（epstdmarc.exe）から内部呼び出しされる状態を意図的に無効にしてください。
（関連FAQ）
●EPSTDMARC を使ってDKIM/DMARC設定したがARC未設定だと epstarc のエラーが出てしまう

3. EPSTDKIM の sign.bat で作成した秘密鍵、暗号鍵は EPSTDMARC に流用できるか。
（DKIM用の情報であるDNSのtxtレコードを登録済みのため、同じDKIMヘッダを付けたい）
はい。EPSTDKIM の sign.bat で作成した秘密鍵と暗号鍵は、EPSTDMARC 導入後にそのまま流用することが可能です。DMARC でも、既に登録済み DKIM の情報でサインやチェックを行います。

4. 一般的な質問となるが、一つの E-Post から複数のサブドメインのメールを送る環境となっている。DNSにサブドメインAの DKIM、DMARC のtxtレコードをそれぞれ追加しても、サブドメインBには特に影響はない想定でよいか。
はい。送信元アドレスの@マーク以降のドメイン名が、サイン＆チェックの条件となり、サブドメイン毎に処理は可能です。可能なら E-Post側へメールを送る際に、送信元サブドメイン毎に接続IPアドレスを指定する設定にすればなおよいです。
（関連FAQ）
