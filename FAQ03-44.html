EPSTRS v4.ANでサービス停止が発生する場合の対処方法 new!

EPSTRSサービスプログラムモジュール（v4.AN）において、特定条件が重なった場合にサービス停止が発生する事象が確認されています。
本FAQでは現象、対象バージョンおよび対処方法について説明します。

1.【現象】
EPSTRSサービスプログラムモジュール（v4.AN）において、以下の条件が同時に発生した場合、EPSTRSサービスが停止することがあります。
  • 高負荷状態で動作している
  • ログ取得を行っている
  • ログファイルのOpen／Close処理が発生するタイミングと重なる
2.【対象バージョン】
対象EPSTRSバージョン
  • EPSTRS v4.AN
対象となる製品・プログラム
●「差分アップデートプログラム 2026.09.10版」収録CD、または以下の差分アップデートプログラムを適用した環境
  • E-Post Mail Server Enterprise II (x64) 20260901差分プログラム
  • E-Post Mail Server Standard (x64) 20260901差分プログラム
  • E-Post SMTP Server Enterprise II (x64) 20260901差分プログラム
  • E-Post SMTP Server Standard (x64) 20260901差分プログラム
● 2026年9月10日以降に弊社から出荷した新規インストールCD
  • E-Post Mail Server Enterprise II (x64)
    ボリュームラベル名：EPMS_Ent_260902
  • E-Post Mail Server Standard (x64)
    ボリュームラベル名：EPMS_Std_260902
  • E-Post SMTP Server Enterprise II (x64)
    ボリュームラベル名：EPSS_Ent_260902
  • E-Post SMTP Server Standard (x64)
    ボリュームラベル名：EPSS_Std_260902
※光学ドライブにCDをセットした際に表示されるCDのボリュームラベル名です。
※上記新規インストールCDには、20260901差分アップデートプログラムが適用された状態のプログラムが収録されています。
※これ以外のボリュームラベル名の新規インストールCDは対象外です。

3.【推奨対策】
本事象は以下の差分アップデートプログラムで修正されています。
  • E-Post Mail Server Enterprise II (x64) 20261030差分プログラム
  • E-Post Mail Server Standard (x64) 20261030差分プログラム
  • E-Post SMTP Server Enterprise II (x64) 20261030差分プログラム
  • E-Post SMTP Server Standard (x64) 20261030差分プログラム
2026年11月5日に「サポート２」へ公開しておりますので、対象のお客様は最新版差分アップデートプログラムをダウンロードして適用してください。

4.【20261030差分アップデート適用まで継続利用する場合】
20260901差分アップデートを適用したまま運用する場合、または対象の新規インストールCDからインストールした環境を継続利用する場合は、一時対策として以下の設定を行ってください。
（1）EPSTRSサービスの回復設定
Windows Serverの「サービス」より「E-Post SMTP Receiver（EPSTRS）」のプロパティを開き、「回復」タブでサービス停止時に自動再起動するよう設定してください。
（2）レジストリ設定
以下のレジストリ値を作成してください。
　HKEY_LOCAL_MACHINE
　　→SYSTEM
　　　→CurrentControlSet
　　　　→Services
　　　　　→EPSTRS
　　　　　　→LogSyncEnabled (DWORD)
　　設定値 デフォルト未設定, 0：排他同期しない 1：排他同期する

設定手順
  1. LogSyncEnabled をDWORD値として作成します。
  2. 値を10進数で「1」に設定します。
  3. EPSTRSサービスを再起動します。
5.【20261030差分アップデート適用後について】
20261030差分アップデート適用後は、本FAQで作成したレジストリ値「LogSyncEnabled」を削除しても、そのまま残しても問題ありません。

6.【補足】
20260901差分アップデートプログラムの提供は終了しています。
対象環境につきましては、20261030差分アップデートプログラムの適用を推奨します。
